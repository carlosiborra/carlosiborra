# Carlos Iborra

**Software & Data Engineer · Madrid, Spain**

[Website](https://carlosiborra.com) · [LinkedIn](https://www.linkedin.com/in/carlos-iborra-llopis-bb84a1214/) · [Email](mailto:contact@carlosiborra.com)

I like understanding how things work by building them.

At work, I build AI and data platforms. Outside work, I experiment with new technologies and create applications, developer tools, and automations of my own. I enjoy the whole process: finding a problem, exploring an idea, designing the experience, and getting the software into a state where people can actually use it.

**My goal is to turn ideas into useful, well-crafted products that solve real problems, and become a better engineer along the way.**

## What I like to build & explore

- **Applications from idea to release.** Web, mobile, and native apps, with as much attention to the experience as to the systems behind it.
- **AI, agents & data.** Useful AI integrations, inspectable agent workflows, and the platforms and pipelines that support them.
- **Tools that remove friction.** Developer tooling, automation, and self-hosted infrastructure. Often, the starting point is something I wish worked better in my own day.

I prefer simple designs, explicit trade-offs, and understanding why something works rather than just getting it to run.

## From my workbench

### [Ralphban](https://github.com/carlosiborra/Ralphban)

**A visual Kanban board for LLM tasks, inside VS Code.**

I built Ralphban because I wanted to see what my agents were doing instead of reading another JSON file. It turns task files into an editable board, with filtering, progress tracking, and live synchronization. The JSON remains the source of truth.

No backend. No accounts. No telemetry.

[**Install for VS Code**](https://marketplace.visualstudio.com/items?itemName=carlosiborra.ralphban) · [Source & documentation](https://github.com/carlosiborra/Ralphban#readme) · [Contribute](https://github.com/carlosiborra/Ralphban/blob/main/CONTRIBUTING.md)
