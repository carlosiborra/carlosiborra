- Preserve the original animated header: https://github.com/user-attachments/assets/8c830821-61ca-4039-b8f2-b0bcaeb29830. The existing local header SVGs are reduced-motion alternatives, not a replacement visual identity.

## Dependencies and privacy

## Visual review before publication

- Carlos rejected the previous layout. Do not equate passing source checks or having fewer widgets with a successful design.
- Read current files and their SHAs before writing; preserve concurrent changes.
- Inspect the exact original header and actual demo at desktop/mobile widths and in both themes. Check their relative scale, spacing, readability, and motion together.
- Never use placeholder media to claim the actual design was visually verified. A local CSS preview is not the live GitHub renderer.
- If media or live rendering cannot be inspected, keep the redesign in a draft PR and state what remains unverified. Do not merge solely because markup tests pass.
