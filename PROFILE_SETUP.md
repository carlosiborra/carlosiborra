# Profile design notes

## Current direction

The profile is intentionally not a repository portfolio.

Its job is to communicate Carlos's engineering identity: a Software & Data Engineer who works around AI and data platforms, likes experimenting with technology, builds applications end to end, and cares about simple, useful systems.

Individual projects are intentionally omitted. University coursework must not be presented as personal product work.

## Visual approach

- Original animated header as the hero.
- Centered name, role, and navigation.
- Short personal introduction.
- Four technical interest areas.
- A compact text-based toolbox.
- No project showcase.
- No statistics dashboard or decorative widget wall.

External widgets were removed because they introduced inconsistent sizing, visual noise, and additional failure modes. The profile should remain coherent even if only GitHub's native Markdown/HTML renderer is available.

## Configuration

No setup is required.

There is no profile workflow, PAT, OAuth connection, WakaTime integration, GitHub Pages deployment, or paid service involved in the current README.

The only required remote visual is the existing GitHub-hosted animated header.

## Future changes

Before adding a widget or project, ask whether it improves one of these goals:

1. explain what Carlos likes to build;
2. make his technical interests clearer;
3. give visitors a useful path to contact or understand him;
4. add evidence that is stronger than the extra visual complexity.

If not, leave it out.
